# Nikke Play Order

A simple release-order checklist for Goddess of Victory: NIKKE. It includes story chapters, events, collaborations, and optional side stories.

The list is not chronological, it is by release date. Check items off as you go; your progress is saved in your browser.

If you want to run it yourself, download the files and open `index.html` to use it.
